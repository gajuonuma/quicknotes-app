# QuickNotes

QuickNotes is a simple browser-based note-taking application built with HTML, CSS, and JavaScript. It allows users to create notes, assign them to Personal, Work, or Study categories, search through saved notes, delete notes, and keep notes stored in the browser using localStorage.

## Features

- Add new notes
- Assign notes to Personal, Work, or Study categories
- Validate notes so they cannot be empty or longer than 200 characters
- Display the number of notes
- Search notes by their text
- Delete notes
- Save notes to localStorage
- Load saved notes when the page is opened again
- Responsive layout for smaller screens
- Different visual styles for each note category
